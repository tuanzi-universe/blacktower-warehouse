- 刷怪笼按要求移除，不生成规则，命中 `trash`；玩家头颅收录至 G-L 玩家的头单元。
- 兜底药水与独立药箭已移除；标准药水/无 `customEffects` 药箭不命中，落 `trash`。
- 多附魔书按 D-L 顺序落到首个命中附魔格。
- `ready` / `readyButton` 沿用现网配置；`ready` 标签为“准备出发点（占位，替换为实际坐标）”。
- HTML 需本地 HTTP 打开；`file://` 会提示 fetch 失败。
